TRANSPARENT FORMULAS

Model the economics. Not the hype.

All fees are entered manually and apply to a single reporting currency. We do not invent platform rates, infer sales, read account data, or claim these results represent accounting profit. Returns are modeled as an expected additional loss per return, which you define.

Expected return cost = return rate × loss per returnUnit profit = price − all fixed costs − price-based fees − expected return costBreak-even price = fixed costs ÷ (1 − total percentage fees)
