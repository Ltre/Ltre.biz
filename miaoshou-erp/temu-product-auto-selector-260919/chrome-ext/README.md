# Temu 商品严选及跨境ERP助手采集（Chrome MV3）

版本：1.3.0

## 本版架构变化

插件不再保存 OpenAI / Anthropic / Gemini / DeepSeek / 中转平台的 API Key、Base URL 等上游凭据。AI 推理统一通过仓库 `server/` 中的通用 AI Relay 服务完成。

插件侧只保存：

- Relay 服务地址。
- 手机号。
- 登录后的短期/长期会话 Token。
- 服务端返回的、当前用户有权限使用的渠道与模型列表。
- 当前选择的 `channel/model-id`。

因此 task 归档也只记录本次使用的渠道/模型，不包含 Relay 登录 Token，更不会包含任何上游 API Key。

## 核心流程

1. 保存“搜索关键词 / 商品筛选规则 / 限制规则”及三组备用提示词。
2. 在 Temu 按关键词搜索、滚动、翻页，并优先执行本地确定性筛选。
3. 信息不足的候选按限制打开详情页二次确认。
4. AI 可按需补充关键词、复核仍为 `review` 的商品。
5. 形成 `task_id` 审核列表，支持“全选可采集 / 反选 / 取消选择”，人工确认后再触发 **跨境ERP助手**（ID `ecofkipcicjifkppbgnkaghcfofmpkia`）页面采集入口。
6. 已采集商品写入历史指纹，后续任务去重。

## AI Relay 登录

AI 推理设置中填写服务端地址与手机号：

1. 用户需要预先关注公众号并发送 `reg:15911111111` 完成轻量注册。
2. 插件点击“发送验证码”。
3. 服务端通过微信向该手机号所绑定的公众号 OpenID 下发验证码；本地 DEV + mock 模式会把调试验证码返回给插件，插件会显示并自动填入验证码框。
4. 输入 6 位验证码登录。
5. 插件从 `/api/models` 获取当前用户有权使用的模型，并按渠道分组展示。

服务端可以随时暂停某个用户的 AI 权限，或精确限制该用户可使用哪些渠道下的哪些模型。

## AI 使用方式

- `关闭（完全不调用）`
- `按需兜底（普通筛选需要时调用）`
- `在出现风控图形验证码时必须用 AI`

第三种模式包含普通筛选的按需兜底行为；同时要求任务绑定一个在服务端标记为 `vision` 的模型。

### Temu 风控图形验证

插件检测到 CAPTCHA/challenge 后，在“必须用 AI”模式下：

1. 激活出现验证的 Temu 标签页。
2. 截取当前可见页面。
3. 将截图和验证页 DOM 摘要发送到 Relay 的视觉模型。
4. AI 只负责判断是否为图形风控验证、识别大致类型（图片点选、图片网格、滑块等）并生成**不包含答案**的人工处理提示。
5. task 记录 AI 检测结果并暂停。
6. 用户在 Temu 页面完成人工验证后，插件轮询检测验证层消失并自动从原阶段继续；仍保留“继续当前任务”作为手动兜底。

插件不会让 AI 求解验证码答案、不会输出点击图片/滑块坐标、不会自动点击验证码、不会伪造指纹或鼠标轨迹来绕过 Temu 风控。

## 跨境ERP助手

- 名称：`跨境ERP助手`
- Chrome 扩展 ID：`ecofkipcicjifkppbgnkaghcfofmpkia`

本插件不访问 ERP 后台，只寻找其注入 Temu 页面中的“采集此产品 / 立即采集 / 采集商品 / 采集”入口并触发。支持自定义 CSS 选择器。

如果跨境ERP助手完全使用不可访问的跨源 `chrome-extension://...` iframe 或 closed Shadow DOM，Chrome 扩展隔离可能使本插件无法操作内部控件；此时任务会暂停，不会误记成功。

## 权限

- `storage`：配置、任务、历史去重、本机 Relay 登录会话。
- `tabs`：Temu 页面切换与详情页访问。
- `activeTab`：在检测到风控验证且策略要求 AI 时截取当前可见 Temu 页面供视觉模型做**验证类型识别**。
- `sidePanel`：侧边栏 UI。
- Temu host permissions。
- `optional_host_permissions`：用户配置自建 Relay 地址后按需授权对应 origin。

## 安装

1. 先部署或本地启动 `server/`。
2. Chrome 打开 `chrome://extensions/` 并开启开发者模式。
3. “加载已解压的扩展程序”，选择 `chrome-ext/`。
4. 确保跨境ERP助手已经安装、登录并刷新 Temu 页面。
5. 打开本插件侧边栏，在 AI 推理设置中填写 Relay 地址并登录。
6. 选择服务端授权的模型后即可使用 AI 兜底。

## 默认示例规则

保持 v1.1.0 的手机膜示例：高清/高透/透明钢化膜、2–4 片装、排除防窥/磨砂/水凝/镜头膜，并支持品牌词、价格、销量、评分、每关键词上限、翻页上限、详情确认上限和历史去重等本地规则。
