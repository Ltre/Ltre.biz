# Temu 商品严选及跨境ERP助手采集（Chrome MV3）

版本：1.1.0

## 核心流程

1. 保存“搜索关键词 / 商品筛选规则 / 限制规则”，下次继续使用。
2. 三项配置各自都有一个“备用提示词”输入框，用于普通结构化规则无法充分表达的需求。
3. 在 Temu 当前标签页按关键词搜索，等待页面加载、滚动列表，并按限制继续分页。
4. 先使用本地确定性规则筛选；信息不足的候选按上限打开详情页二次确认。
5. 可选开启 AI 兜底：
   - 搜索关键词备用提示词：任务开始时最多调用一次，用来补充搜索词。
   - 商品筛选规则 / 限制规则备用提示词：只复核确定性规则 + 详情页后仍为 `review` 的候选。
   - AI 默认关闭，不会在每个商品上调用。
6. 生成 `task_id` 任务归档和审核列表。
7. 用户确认后点击“执行采集”，逐个打开详情页并触发 **跨境ERP助手** 注入 Temu 页面的采集入口。
8. 已采集商品进入历史指纹库，后续任务默认排除重复。

## 跨境ERP助手

正确扩展信息：

- 名称：`跨境ERP助手`
- Chrome 扩展 ID：`ecofkipcicjifkppbgnkaghcfofmpkia`

本插件不访问 ERP 后台接口，只寻找跨境ERP助手注入 Temu 页面中的“采集此产品 / 立即采集 / 采集商品 / 采集”入口并触发。

适配优先级：

1. 用户在高级设置填写的 CSS 选择器。
2. 页面普通 DOM / 开放 Shadow DOM 中匹配的采集按钮。
3. 按按钮文本和 ERP/扩展特征评分选择最可信入口。

如果跨境ERP助手将界面完全放入不可访问的 `chrome-extension://ecofkipcicjifkppbgnkaghcfofmpkia/...` 跨源 iframe 或 closed Shadow DOM，Chrome 的扩展隔离机制可能阻止另一个扩展直接操作其中控件。插件会明确暂停，不会把失败误记为成功。

## AI API 配置

支持保存多套 AI 配置、切换当前配置：

- OpenAI（Responses API）
- Anthropic（Messages API）
- Google Gemini（`generateContent`）
- DeepSeek（OpenAI 兼容 Chat Completions）
- 自定义 OpenAI 兼容中转

每个配置可保存：

- 配置名称
- 平台
- Base URL
- 模型 ID
- API Key
- 可选自定义 API Path

Base URL 是可编辑的，因此 Anthropic/Gemini/OpenAI 等平台也可指向符合对应协议的自建中转。自定义 OpenAI 兼容中转默认使用 `/v1/chat/completions`。

扩展通过 `optional_host_permissions` 按需申请当前 AI API 域名访问权限，不在安装时默认获得所有外站访问权限。

> API Key 保存在本机 `chrome.storage.local`。它不会进入 task 归档或导出的任务 JSON，但 Chrome 扩展本地存储并不是专门的密码保险箱，建议使用专用 Key、限额和最小权限。

## AI 调用策略

目标是让日常筛选尽量不需要推理费用。

### 本地规则优先处理

- 高清 / 高透 / 防窥 / 磨砂 / 水凝 / 钢化 / 镜头膜 / 屏幕膜等文本特征。
- `2pcs / 3片装 / pack of 3` 等数量提取。
- 价格、销量、评分阈值。
- 商标/品牌黑名单。
- Temu 商品 ID 去重。
- 归一化标题 Dice 相似度去重。
- 跨 task 历史已采集去重。

### AI 只做兜底

当 AI 模式为“按需兜底”时：

- `搜索关键词备用提示词` 非空：最多调用一次，返回额外搜索词。
- `商品筛选备用提示词` 或 `限制规则备用提示词` 非空：只复核仍然处于 `review` 的候选。
- AI 置信度低于 0.75 时仍保持 `review`，不会强行通过/排除。
- 确定性规则已经明确排除的商品不会被 AI 翻案。
- AI API 调用失败会记录在 task 日志中，任务继续保留人工审核路径。

task 会记录 AI 配置 ID、平台、模型和调用次数，但不记录 API Key。

## Temu 验证与访问节奏

Temu 页面可能出现安全验证、CAPTCHA、滑块或访问异常提示。本插件的处理原则：

- 通过页面文字、iframe、challenge/captcha DOM 特征检测验证页面。
- 一旦检测到验证，暂停任务并提示用户在 Temu 页面手动完成。
- `task` 记录暂停阶段：筛选阶段验证完成后继续筛选；采集阶段验证完成后继续未采集条目。
- 不自动破解 CAPTCHA/滑块，不伪造浏览器指纹、鼠标轨迹或其它绕过反爬验证的行为。

高级设置提供：

- 换关键词/翻页最短和最长等待时间。
- 详情页之间最短和最长等待时间。
- 采集条目之间等待时间。

随机区间等待的目的只是降低请求密度、适应 Temu 较慢的动态页面加载，并非规避安全验证。

## 默认示例

### 搜索关键词

- iphone手机膜
- iphone钢化膜
- 三星钢化膜
- Samsung Galaxy钢化膜

### 商品筛选规则

- 只要高清/高透/透明钢化膜
- 不要防窥膜、磨砂膜、水凝膜/软膜
- 2-4片装
- 手机屏幕膜，不要镜头膜

### 限制规则

- `规避商标/品牌词：Spigen, ESR, ZAGG, Belkin, OtterBox`
- `允许兼容品牌词：iPhone, Apple, Samsung, Galaxy`
- `同一任务标题相似度 >= 0.82 视为重复`
- `历史已采集商品不要重复`
- `每个关键词最多扫描80个商品`
- `最多翻3页`
- `最多打开20个详情页确认`

另外支持：

- `价格 <= 10`
- `价格 >= 2`
- `销量 >= 100`
- `评分 >= 4.5`
- `最多滚动 10 次`

## 安装

1. 解压 ZIP。
2. Chrome 打开 `chrome://extensions/`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择本目录。
5. 确保 `跨境ERP助手`（ID `ecofkipcicjifkppbgnkaghcfofmpkia`）已安装、登录，并刷新 Temu 页面。
6. 点击本插件工具栏图标打开侧边栏。
7. 如需 AI，在“AI 推理设置”中新建配置并点击“测试连接”。Chrome 会按需询问对应 API 域名访问权限。

## 本地数据

以下数据保存在 `chrome.storage.local`：

- 表单和三组备用提示词。
- AI 配置（包括 API Key）。
- 高级节奏/ERP 适配配置。
- task 归档、候选商品、task_id、日志和 AI 调用统计。
- 历史已采集商品指纹。

插件没有自建服务端。
