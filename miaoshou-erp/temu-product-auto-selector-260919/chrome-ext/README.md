# Temu 商品严选及妙手采集（Chrome MV3）

## 功能

1. 保存“搜索关键词 / 商品筛选规则 / 限制规则”，下次继续使用。
2. 在当前 Chrome 标签页内驱动 Temu 搜索，滚动列表并在存在分页时继续翻页。
3. 对商品列表做确定性筛选；信息不足的候选会按限制数量打开详情页二次确认。
4. 生成带 `task_id` 的任务归档和审核列表。通过/需人工确认的商品可勾选，排除商品默认隐藏。
5. 审核后点击“执行采集”，逐个打开商品详情页，并尝试点击妙手 ERP 注入页面的“采集此产品 / 立即采集 / 采集”入口。
6. 已执行采集的商品进入本地历史指纹库，后续任务默认排除重复商品。
7. 当前版本不调用 AI API：无法可靠判断的商品进入人工复核，不产生推理费用。

## 安装

1. 解压 ZIP。
2. Chrome 打开 `chrome://extensions/`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择本目录。
5. 同时确保妙手 ERP 官方插件已安装、登录，并刷新 Temu 页面。
6. 点击浏览器工具栏中的本插件图标，会打开侧边栏。

## 默认示例

### 搜索关键词

- iphone手机膜
- iphone钢化膜
- 三星钢化膜
- Samsung Galaxy钢化膜

### 商品筛选规则

- 只要高清/高透/透明钢化膜
- 不要防窥膜、磨砂膜、水凝膜/软膜
- 2-4片装
- 手机屏幕膜，不要镜头膜

### 限制规则

- `规避商标/品牌词：Spigen, ESR, ZAGG, Belkin, OtterBox`
- `允许兼容品牌词：iPhone, Apple, Samsung, Galaxy`
- `同一任务标题相似度 >= 0.82 视为重复`
- `历史已采集商品不要重复`
- `每个关键词最多扫描80个商品`
- `最多翻3页`
- `最多打开20个详情页确认`

另外支持：

- `价格 <= 10`
- `价格 >= 2`
- `销量 >= 100`
- `评分 >= 4.5`
- `最多滚动 10 次`

## 筛选策略

### 不需要 AI 的部分

- 高清/防窥/磨砂/水凝/钢化/镜头膜等文本类型识别。
- `2pcs / 3片装 / pack of 3` 等片数提取。
- 价格、销量、评分阈值。
- 黑名单品牌/商标词。
- Temu 商品 ID 去重。
- 归一化标题 3-gram Dice 相似度去重。
- 跨 task 历史已采集去重。

### 为什么当前版本不接 AI

日常筛选绝大多数条件都能由确定性规则稳定处理。AI 对“图片里是否出现商标”“标题描述非常含糊但图片可判断”等场景才有明显价值；这类候选当前标为“需人工确认”。这样能避免每次翻页、每件商品都调用模型。

后续如果确实需要，可只对 `decision=review` 的少量候选增加视觉/LLM 二次判定，而不是对全部商品调用 AI。

## 妙手 ERP 适配说明

妙手官方流程支持 Temu 列表页采集以及详情页“采集此产品”。本插件不访问妙手后台接口，只在 Temu 页面上寻找妙手注入的可点击入口。

自动识别优先级：

1. 高级设置中的自定义 CSS 选择器。
2. 页面/开放 Shadow DOM 中的“采集此产品”。
3. “立即采集 / 采集商品 / 采集”等文本按钮，并优先包含 `miaoshou / 91miaoshou / msfetch / 妙手` 特征的节点。

Chrome 扩展之间存在隔离。如果某一版妙手把按钮完全放入不可访问的 `chrome-extension://...` 跨源 iframe 或 closed Shadow DOM，另一个扩展不能直接读取其内部 DOM。此时本插件会暂停而不是假装成功。若妙手按钮仍是 Temu 页面普通 DOM（其官方插件常见做法），则可以直接触发。

## 人机验证

不绕过 CAPTCHA/滑块验证。检测到 Temu 安全验证时任务暂停，用户手动完成后可继续筛选；采集阶段验证后可再次点“执行采集”，已完成的条目不会重复。

## 本地数据

全部任务配置、候选商品、task_id、历史采集指纹均保存于 `chrome.storage.local`。插件没有自建服务器，也不会把这些数据上传到第三方。
