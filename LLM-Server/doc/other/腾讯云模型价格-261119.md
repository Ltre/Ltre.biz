统一换算公式：

\\[ \text{单张费用}=\frac{\text{单张Token消耗}\times\text{每百万Token单价}}{1,000,000} \\]

例如，10 元/百万 Token，生成一张消耗 15,000 Token，实际费用就是 **0.15 元/张**。
